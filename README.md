# FOOTBALL ANALYZER

日本語・端末内保存のサッカー分析アプリ。React / TypeScript / Vite / IndexedDB / Three.js。

公開URL: https://football-analyzer-hk-20261105.football-analyzer.workers.dev

## 起動

Node.js 22 以上を使用します。

```powershell
npm ci
npm run dev
```

表示された localhost のURLを開きます。Windowsで保存パスに `#` が含まれる場合、一部の開発ツールが正しく動きません。英数字のみのローカルフォルダーへプロジェクトをコピーして実行してください。

```powershell
npm run lint
npm run typecheck
npm run test
npx playwright install chromium
npm run build
npm run test:e2e
npm run preview
```

## 基本操作

1. チーム・選手画面でチームを登録し「このチームで分析」を押します。
2. 試合を登録します。初期選択の「標準分析」はゲームモデルなしで使えます。独自原則で評価する場合のみ、ゲームモデルを作成・公開してください。
3. 動画を読み込み、対象チーム・時間帯を選びます。標準イベントのクイックタグは現在時刻の前後5秒を保存。自由タグも追加できます。
4. タグを開いて区間・選手・評価・コメント・描画を編集します。チーム・前後半・イベント・評価・検索語で絞り込み、連続再生やクリップ編集ができます。
5. ダッシュボードで集計、レポートで練習課題を記入します。モデルを変更するときは新しい下書き版を作ります。
6. タグから戦術盤を開き、2D配置と5秒ごとのキーフレームを編集して保存します。3D・選手目線でも再生できます。
7. 設定からJSONバックアップを定期的に保存します。

## 保存・プライバシー

- データはサイトのオリジンごとのIndexedDBに保存されます。サーバーには保存されません。
- 動画・骨格データのアップロード機能、アクセス解析、外部フォントはありません。
- ホーム画面下部に忍者AdMaxの300×250広告を表示します。広告配信時は外部サービスとの通信が発生します。表示開始時の画面幅が767px以下ならスマホ用の `public/ads/admax-mobile.html`、それより広ければPC用の `public/ads/admax.html` を、Reactから独立したiframeで一方だけ読み込みます。表示中のサイズ変更では広告を再読込しません。
- ローカルファイルはセッション中だけ参照します。再起動後は同じ動画を選び直します。JSONに動画本体は含みません。
- ブラウザーのデータ削除、プライベートモード終了、端末故障に備え、JSONと元動画を別途保管してください。
- バックアップ復元はスキーマと参照を検証します。同じIDで内容が異なる場合は既存記録を上書きせず中止します。空のブラウザーに復元してください。
- 本番サイトはアプリのコードのみ配信します。公開URLを知る人が他の端末の分析データを見ることはできません。ただし同じブラウザープロファイルを使う人同士はデータを共有します。
- Service Workerは閲覧済みの同一サイトのアセットをキャッシュします。初回読み込みには通信が必要です。完全なオフライン利用の検証はFEATURE_STATUSを参照してください。

## 集計定義

実践度 = good / (good + improve) × 100。保留と対象外を除外し、分母が0なら「—」を表示します。コーチが手動で抽出した場面の実践度であり、全プレーの成功率ではありません。初期版は試合単位で集計し、異なるモデル版を自動統合しません。

## 動画と3D

- 対応ブラウザー：現行のデスクトップChrome / Edgeを主な検証対象とします。形式、OS、GPUにより利用できない機能があります。
- 動画編集は単一の元動画から区間を選び、並び替え・分割・速度・字幕・タグ描画を適用します。
- 出力は映像のみ。音声合成は未対応です。MP4を利用可能なら優先し、WebMにフォールバックします。拡張子の偽装はしません。
- MediaRecorder対応判定だけでは成功を保証できないため、生成Blobの映像フレームを読み込んで確認します。ユーザーも生成プレビューを再生してください。
- 720p、合計10分までのクリップ編集を初期仕様としています。処理中はタブを開いたままにします。バックグラウンドタブでは描画・録画が停止または遅延することがあります。
- 3Dは自作プリミティブの手動配置です。選手・ボールを直線補間します。実映像からの自動復元や実際の視野計測ではありません。
- 戦術動画をダウンロード後、編集画面で元動画として読み込めます。試合映像と戦術動画を混在させる複数素材編集は未対応です。

## MediaPipe（実験機能）

姿勢推定のWASMは同一サイトから読み込みます。Pose Landmarkerの`.task`モデルをユーザーが選択します。モデルは配布物に同梱していません。動画1を約6fpsで推論し、33点のランドマークと両膝の2D角度を表示します。信頼度不足の角度は空欄にします。推論はメインスレッドのCPUで行うため高負荷端末では重くなることがあります。怪我のリスクや医学的診断を判定しません。実素材での検証状況はFEATURE_STATUSを参照。

## ライブ撮影とタグ付け

試合を登録し、分析画面の「カメラを起動」から背面カメラを開きます。録画中はイベントボタンで時刻を記録でき、自チーム／相手、前半／後半、選手、タグ前後の再生秒数を指定できます。自由タグは撮影中にも追加できます。

- HTTPS（開発時は localhost）とカメラ利用許可が必要です。音声録音は任意です。
- ハーフタイムは「一時停止」、後半を選んで「録画を再開」。タグ時刻は休憩を除いた動画上の秒数です。
- 画面を閉じたりロックしたりせず撮影してください。非表示・カメラ中断を検出すると一時停止します。
- 映像は約2秒ごとのデータに分け、タグとともにブラウザー内へ保存します。動画のサーバー送信はありません。容量不足時は録画を止め、退避できる映像のファイル保存を案内します。
- 録画終了後は再生可否を確認し、既存の分析・クリップ編集に接続します。再読み込み時も端末内の録画を復元します。異常終了時は「保存済みの録画を復元」を選びますが、保存前に終了した部分や未完成の動画は復元できない場合があります。
- 録画はJSONバックアップに含まれません。「撮影動画をファイルに保存」で別途保管してください。サイトデータ削除で録画も失われます。
- 既存の映像・タグがある試合への新規録画は防ぎます。別の録画は新しい試合として登録してください。

新規試合は標準イベントが既定です。独自の分析項目は「カスタム分析（任意）」に残しており、過去のゲームモデルに紐づいた記録はそのまま参照できます。

### 録画の検証

npm test に録画時間・タグ区間のテスト、tests/live-capture.spec.ts にテスト用カメラによる録画・一時停止・保存・再読み込み・権限拒否のテストがあります。Playwright付属ブラウザーがない環境では、インストール済みChromeを PLAYWRIGHT_CHANNEL=chrome で使用できます。スマホ実機の長時間録画、発熱・空き容量・着信時の挙動は別途確認が必要です。


## 戦術ボードの表示・全画面

- 「名前を表示」「背番号を表示」は個別に切り替えられます。「保存」でプロジェクトに保存され、2D・3D・生成動画にも反映されます。
- ボールの「次のフレームまでの球種」で「演出なし」を選ぶと、位置は移動しますが軌道線・矢印・浮き上がりを表示しません。既存のグラウンダー・浮き球・ドリブルも選択できます。
- 「全画面で表示」でピッチが画面の幅・高さ全体を使います。操作欄は通常隠れ、「操作を表示」でピッチの上に重ねて開きます。「操作を隠す」で閉じ、「全画面を終了」またはEscで元に戻ります。2Dは画面の形に合わせた模式表示で、スマホ縦向きではピッチを縦に配置します。選手名・背番号は正位置で表示します。ブラウザーの全画面APIが使えない端末でも、ブラウザー内の表示領域をいっぱいに使います。

## ホーム画面への追加とQRコード

画面上部の「ホーム画面・QR」から、iPhone・iPad・Android・PC向けの追加手順と公開URLのQRコードを開けます。対応ブラウザーでは「この端末に追加」からインストールを開始できます。追加の最終操作は端末側で行います。QRコードはアプリを開くURLであり、端末内の試合データを共有するものではありません。

QR画像とホーム画面アイコンは public 内に同梱しています。再生成は scripts/generate-install-assets.py（Pillow・qrcodeが必要）で行えます。

### 端末内データの管理
全画面共通の「設定」から設定・データ管理を開けます。JSONバックアップ・復元、保存容量、データ件数、アプリ内録画の書き出し、録画だけの削除、全データ初期化に対応します。JSONには動画本体を含みません。削除前に必要な録画を別途書き出してください。削除は確認画面で「削除」と入力して確定します。対象はこのブラウザー内の全チームです。元の動画ファイルや他端末のデータは削除しません。他のタブは閉じてから操作してください。

## 試合映像と図によるタグ付け
- 「集計」「レポート」を「集計・レポート」に統合。旧 /dashboard も同じ機能を表示します。
- 動画とタグ欄を一画面に配置。タグの詳細欄だけをスクロールでき、イベントボタンは欄の下部に固定します。スマホではイベント一覧を横に送れます。
- ピッチ図は攻撃方向を上とする3エリア（守備・中盤・攻撃）×5レーン（左ワイド・左ハーフスペース・中央・右ハーフスペース・右ワイド）。対象チームの攻撃方向に対する位置です。
- 位置、GOOD/BADは任意。選択してイベントを押すとその時刻を記録し、位置・評価は未指定に戻ります。既存タグの編集、撮影タグ、JSONバックアップ、エリア・レーンの絞り込み、集計CSVにも対応します。従来の評価値と位置のないタグを引き続き読めます。

## 戦術ボードの配置・向き・演出

- 人数を選ぶと、その人数用の基本フォーメーションを選べます（人数はGKを含み、配置名の数字はGKを除きます）。既存フレームにも味方・相手別に配置を適用できます。
- 「選手の向き」で選手を選び、向けたい場所をクリック／タップします。選手からドラッグして向けることもできます。2D・3Dで利用できます。
- 「元に戻す」「やり直す」で現在の編集履歴を最大60操作まで戻せます。ドラッグは1操作です。Ctrl/Cmd+Z、Shift+Zにも対応します。プロジェクトの切り替え・再読み込みで履歴はリセットされます。
- 「矢印」「サークル」はドラッグ、「リンク」は2つの選手・ボールを順に選択、「強調」はクリック／タップで追加します。色と破線を選択できます。演出一覧から削除もできます。
- 演出はフレームごとに保存され、次フレームの追加時に複製されます。選手やボールに付けた演出は移動に追従し、2D・3D表示に反映されます。

## ハイライト編集（第2段階）

試合の「クリップ編集」または集計画面の「この集計の場面をハイライトへ」から開きます。

- タグ・選手・対象チーム・GOOD/BAD・3エリア×5レーンで複数試合の場面を抽出できます。同名イベントは試合をまたいで検索します。集計表の件数からも編集へ送れます。
- 映像とタイムラインを同時表示。区間変更、分割、複製／リプレイ、ドラッグでの並べ替えとタッチ向け前後移動に対応します。
- 部分スローは分割した区間に速度を設定します。現在位置へフリーズを挿入でき、静止秒数を変更できます。ズームと表示中心も変更できます。ズームを決めてから描画を配置してください。
- 矢印、円、リンク、自由線、エリア、選手名、テキストなどに表示開始・終了を指定。位置・大きさ・色・線幅・透明度を変更できます。
- 手動追従では時刻を変えて「映像をタップして追従点を追加」で位置を登録します。点の間を補間し、表示終了で追従を止めます。自動人物追跡ではありません。
- 自動保存、最大60操作のUndo/Redo、複数編集案の作成・複製・切り替えに対応。試合ごとの編集案と描画・追従点・素材名をJSONバックアップに含めます。動画本体は含まれません。外部ファイルは再開時に同じ素材を選び直してください。アプリ内で撮影・保存した動画は、このブラウザーに残っていれば自動で読み込みます。
- 複数試合の素材、戦術ボードで生成・保存した動画、その他の動画を1本へ結合できます。比較欄ではGOOD/BAD等の別クリップの元映像を確認できます。2画面を合成した動画出力は第3段階の対象です。
- 連続プレビュー、描画付きPNG、720p・合計10分以内のMP4出力。MP4に描画・字幕・ズーム・スロー・フリーズを反映し、元音声を保持します。フリーズ部分は無音です。描画の追従は出力時12fpsで補間します。
- 音声解説、クラウド保管・アクセス制限付き共有、AIによる自動追従は今回の対象外です。素材は端末内で処理します。

### 描画の直接調整と再生位置
ハイライトの「描画」で図形をクリック／タップすると選択できます。本体をドラッグして移動、白い丸で調整します。矢印・ライン・リンクは両端、円・リング・スポットライトは上下左右、四角形・自由線・エリア・文字は四隅で調整します。新規作成は「描画を追加」または描画ツールの選択から行います。作成中も実際の図形を表示します。1回のドラッグはUndoの1操作です。
再生欄に前コマ・次コマ（1/30秒刻み）、±5秒、再生位置のタイムラインを配置しています。動画固有のフレームレートを自動判定するものではありません。

### 時刻別の描画・演出と複数選手リンク
- 「時刻別に位置・形を編集」を有効にし、再生位置を変えて図形や白い丸を動かすと、その時刻の状態を記録します。位置・大きさ・透明度・各選手の輪の位置を補間します。記録時刻の変更・削除、表示開始／終了の設定ができます。時刻は選択したクリップ内の完成時間です。
- 「選手間リンク」は映像内の選手の中心を順にクリック／タップし、「リンクを確定」します（2〜22人）。各選手を輪で囲み、指定順に輪の間を線で結びます。各輪の白い丸で選手ごとの位置を調整できます。
- 「演出 → 時間指定のズーム」で開始・終了秒、拡大率、中心を設定し「指定区間にズームを適用」。動画を分割せず、指定区間だけ拡大します。ズームは記録点の時刻で切り替わります。スローは分割した区間に速度を設定します。
- 描画の時刻別状態とリンクは編集案・JSONバックアップに保存し、PNG・MP4にも反映します。MP4の描画補間は12fpsです。

### 描画・演出ごとのタイムライン
「描画」「演出」を開くと、映像の下に各描画・ズームの時間帯を表示します。始・終のハンドルで表示開始／終了、帯で区間全体、◆で位置変更の記録時刻をドラッグできます。帯を移動すると記録点も一緒に移動します。記録点同士の順序は保持します。
スマホ・iPadは44px以上の操作点を使用。開始・終了・記録点を上下に分け、背景のスワイプで横スクロールできます。「時間軸の拡大」で2・4・8倍にすると細かく調整できます。キーボードの左右矢印は1/30秒、Shift併用は1秒です。1ドラッグを1回のUndoで戻せます。
ズームは動画を分割せず独立した演出として保存します。ズームの行を選ぶと設定を編集でき、「現在時刻のズーム位置を記録」で位置の切り替え点を追加できます。重なる時間帯では後から追加したズームを優先します。表示とMP4出力は同じ時間帯・切り替え点を使用します。既存のクリップ全体ズームは読み込み時に全区間の演出として表示します。

### 編集メニュー（2026-11-07更新）
ハイライトは「クリップ」「描画」「演出」の3タブです。動画の追加と元動画の再選択は「クリップ」から行います。「再生」は選択中のクリップだけを再生します。クリップ名を入力すると時間帯にも表示されます。描画を選択してDeleteキーで削除し、元に戻すことができます。
テロップはクリップ内で文字・サイズ・色を入力し、映像上でマウス／指で移動します。表示時間はテロップの帯の両端で調整します。戦術ボードは「選手名・背番号を一覧入力」と「配置／描画／演出」を使用し、ボールの既定は演出なしです。
